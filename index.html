🔧 Firebase Setup

To sync this leaderboard live across all devices:

  1. Go to console.firebase.google.com → Create project
  2. Add a Web app → copy the config object
  3. Go to Build → Realtime Database → Create database → Test mode
  4. Open this HTML file in a text editor, find the FIREBASE_CONFIG block near the top, and replace each PASTE_… value with yours
  5. Save and share the file — it syncs live!

Everyone uses the same HTML file. Admins log in with the password; everyone else opens it to view the live leaderboard.
